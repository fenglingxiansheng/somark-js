# somark-js

[![Node >=18](https://img.shields.io/badge/node-%3E%3D18-brightgreen)](https://nodejs.org/)
[![License: Apache 2.0](https://img.shields.io/badge/license-Apache%202.0-blue)](./LICENSE)
[![npm version](https://img.shields.io/npm/v/somark-js)](https://www.npmjs.com/package/somark-js)

[SoMark](https://somark.ai) 官方 JavaScript/TypeScript SDK 与命令行工具。

这个仓库是 SoMark SDK + CLI 统一规范的 JavaScript/TypeScript 实现。Python 实现在 [`somark-py`](https://github.com/SoMarkAI/somark-py)。同一个产品目标，两种语言生态。

## 安装

```bash
npm install somark-js
```

## 文档

官方文档请阅读：[docs.somark.tech/documentation](https://docs.somark.tech/open-source-tools)。

认证、CLI、SDK 示例、异步任务、本地预览、PDF 工具、API 参数和错误处理都在那里。README 只保留入口信息，避免长成另一份更难维护的文档。

## 环境要求

- Node.js 18+
- 远程解析和用量查询需要 SoMark API Key
- 本地 PDF 工具与 SoMarkDown 预览不需要 API Key
